# 🌍 Timezone Converter

A **Timezone Converter** built using **HTML, CSS, and JavaScript** that allows users to convert date and time between different time zones accurately using JavaScript’s built-in **Internationalization (Intl) API**.

This project works completely on the **client side** and does not require any external API or backend.

---

## 🚀 Features

- ⏰ Convert date & time between multiple time zones
- 🌐 Supports major global time zones (IST, UTC, USA, UK, Japan, etc.)
- 🔄 Accurate conversion with daylight saving support
- ⚡ Instant conversion using JavaScript
- 💻 Fully client-side (works offline)
- 🎯 Simple and user-friendly interface

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Date handling and conversion logic  
- **Intl.DateTimeFormat API** – Timezone conversion
